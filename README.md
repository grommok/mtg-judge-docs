# mtg-judge-docs
Repository containing MTG Judge documentation. Versioning starting from 16/09/2026.

## Contents

1. **MTR.txt**:

      A plaintext copy of the latest Magic: The Gathering Tournament Rules, as found [HERE](https://wpn.wizards.com/en/rules-documents)
2. **IPG.txt**:

      A plaintext copy of the latest Magic Infraction Procedure Guide, as found [HERE](https://wpn.wizards.com/en/rules-documents)
2. **CR.txt**:

      A plaintext copy of the latest Magic: The Gathering Comprehensive Rules, as found [HERE](https://magic.wizards.com/en/rules)
